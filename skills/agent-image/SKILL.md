# AgentImage

AgentImage 是 AgentRelay 的图片识别中继：把本地图片发给已配置好、支持识图的
线上模型 Provider，拿回详细描述。核心价值：**即使本地 Agent 模型（或 Commander
的本地 9B 辅助模型）不支持识图，也能借线上模型理解图片，避免把识图压力放在
主模型上浪费资源。**

用户真正要求"agent-image"、"识别这张图片"、"描述一下这张图"、"你看一下这个
图片，按图改 bug"（且本地模型不支持图片）时，使用本 Skill。"调用 agent-image"
等价于明确请求立即执行。

## 两种用法（先看用户意图，再决定输出方式）

1. **转述模式**：用户问的是"这张图是什么/写了什么"——执行后把脚本 stdout 的
   描述**原样转述**给用户，不要改写、不要补充脚本没有说的内容。
2. **自用模式**：用户的意思是"你自己看懂这张图，然后继续干活"（例如"按图片
   上的报错改 bug""按这个界面截图修样式"）——**不要把描述全文转述给用户**，
   自己消化描述内容，直接继续执行任务，在回复里简要说明"已通过线上模型理解
   图片"即可。

判断不了的按转述模式处理，并问一句用户想要哪种。

## 执行流程

1. **收集图片路径**：从用户消息和当前上下文中收集图片的**本地文件路径**
   （jpg / jpeg / png / webp / gif / bmp）。一次最多 5 张。
   - 用户给了路径就直接用；
   - 用户只说"这张图"而上下文中没有可定位的文件路径时，向用户索要路径，
     不要凭空猜测、不要搜索无关目录。
   - 用户没有调用本 Skill、只是普通对话时：按没有图片的方式照常处理即可。
     如果本地模型不支持图片，它会自己回复"无法看见图片"之类的话，**这句话
     原路转述给用户**，用户自然知道当前模型不支持识图。
2. **调用脚本**（必须用 agentrelay 独立环境的 Python）：

   ```bash
   "${CODEX_HOME:-$HOME/.codex}/agentrelay-env/bin/python" \
     "${CODEX_HOME:-$HOME/.codex}/skills/agent-image/scripts/agent_image.py" \
     /path/to/image1.png /path/to/image2.jpg
   ```

   - 可选 `--provider <id>` 优先使用某个网页 Provider；失败后脚本会自动切换
     其他候选。
   - 可选 `--question "额外要求"` 追加用户的特殊描述要求（例如"重点读图中的文字"）。
   - 可选 `--no-cache` 强制重新识别（默认同一张图 7 天内命中缓存直接返回）。
3. **处理结果**：
   - 正常输出 = 线上模型对图片的详细描述，按上述两种模式处理。
   - 脚本中途的 `[Provider] xxx 失败（原因），切换下一个候选` 说明发生了自动
     切换，**如实转述**切换信息，让用户知道哪个模型出了问题。
   - 输出以 `【AgentImage 注】` 开头 = 所有候选模型都失败了，里面列出了每个
     Provider 的失败原因和建议（通常是重新运行 install.py 写入 Cookie）。
     **原样转述**，引导用户重新登录或检查配置。

## 识图后的追问闭环

识图成功后，如果用户就**同一张图**继续追问（"图里那段代码什么意思""这个报错
怎么修"），直接用 agent-relay 正常追问即可：网页 Provider 的会话是绑定的，
上下文连续，不需要重新调用 agent-image，也不需要重新满足权重门槛。

## Provider 选择顺序（脚本自动处理，Agent 不需干预）

1. 显式 `--provider` 指定、且支持识图的网页 Provider；
2. 默认网页 Provider（当前配置下支持识图时，例如 DeepSeek 混合模式）；
3. 其他已启用且支持识图的网页 Provider（前一个失败时自动切换）；
4. 配置时确认/探测为支持识图（vision=true）的本地模型（OpenAI 兼容接口直接调用）；
5. 全部失败：注入 `【AgentImage 注】` 说明并正常退出，由主 Agent 转述并引导
   用户重新配置。

## 边界

- 不绕过任何人机验证；网页 Provider 需要有效的登录状态，失效时会提示重新登录。
- 不把线上模型的描述当作绝对事实；图中关键信息（如数字、代码、报错文字）
  必要时提醒用户以原图为准。
- 图片只在调用时发送给选定的模型，不做无关备份；识别结果缓存 7 天用于
  去重，过期自动清理。
- 本 Skill 只处理"把图片发给线上模型识图"这一件事；普通文字求助仍走
  agent-relay。
